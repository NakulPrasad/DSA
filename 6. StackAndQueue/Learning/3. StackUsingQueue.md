# Algorithm


#### **1. push(x):**
**Input:** An integer `x` to be pushed onto the stack.

**Steps:**
1. Enqueue `x` into the queue.
2. Get the current size of the queue.
3. Rotate the queue by removing and re-adding the front element `size - 1` times.  
   This brings the newly added element to the front of the queue (acts like the top of the stack).

---

#### **2. pop():**
**Output:** Removes and returns the top element of the stack.

**Steps:**
1. If the queue is **not empty**, remove and return the front element.
2. Otherwise, return -1 or handle underflow as needed.

---

#### **3. top():**
**Output:** Returns the top element without removing it.

**Steps:**
1. If the queue is **not empty**, return the front element (`peek`).
2. Otherwise, return -1 or handle empty stack case.

---

#### **4. empty():**
**Output:** Returns `true` if the stack is empty, else `false`.

**Steps:**
1. Return `true` if the queue is empty; otherwise, return `false`.

## Pseudo-Code

```java

Initialize:
    Create an empty queue

Function push(x):
    ENQUEUE x into queue
    size ← SIZE of queue
    FOR i ← 1 TO size - 1 DO
        temp ← DEQUEUE from queue
        ENQUEUE temp back into queue
    END FOR

Function pop():
    IF queue is NOT empty THEN
        RETURN DEQUEUE from queue
    ELSE
        RETURN -1 // or handle empty stack case
    END IF

Function top():
    IF queue is NOT empty THEN
        RETURN FRONT element of queue
    ELSE
        RETURN -1 // or handle empty stack case
    END IF

Function empty():
    RETURN TRUE if queue is empty, otherwise FALSE


```
