Problem : [GeeksForGeeks](https://www.geeksforgeeks.org/problems/infix-to-postfix-1587115620/1)


# Algorithm:

1. Scan the infix str from left to right.
2. If the scanned character is an operand, put it in the postfix str.
3. Otherwise, do the following
   If the precedence of the current scanned operator is higher than the precedence of the operator on top of the stack, or if the stack is empty, or if the stack contains a ‘(‘, then push the current operator onto the stack.
   Else, pop all operators from the stack that have precedence higher than or equal to that of the current operator. After that push the current operator onto the stack.
4. If the scanned character is a ‘(‘, push it to the stack.
5. If the scanned character is a ‘)’, pop the stack and output it until a ‘(‘is encountered, and discard both the parenthesis.
6. Repeat steps 2-5 until the infix str is scanned.
7. Once the scanning is over, Pop the stack and add the operators in the postfix str until it is not empty.
8. Finally, print the postfix str.

Time : O(N)
Space : O(N)


## Pseudo-Code:
```java

/*Helper function for precedence */
Function precedence(char ch):
    If ch is '^': return 3
    If ch is '*' or '/': return 2
    If ch is '+' or '-': return 1
    Else: return -1
```

```java
Function infixToPostfix(String str):
    Initialize an empty stack for operators // + - * /
    Initialize an empty string for the result (postfix)

    For each character ch in the str:
        If ch is an operand (letter or digit):
            Append ch to the result
        Else if ch is '(':
            Push ch to the stack
        Else if ch is ')':
            While stack is not empty AND top of stack is not '(':
                Pop from stack and append to result
            Pop '(' from the stack (do not add to result)
        Else if ch is an operator (+, -, *, /, ^):
            While stack is not empty AND precedence(ch) <= precedence(top of stack):
                If ch is '^' AND top of stack is also '^':  // right-associative
                    Break the loop
                Else:
                    Pop from stack and append to result
            Push ch to the stack

    While stack is not empty:
        Pop from stack and append to result

    Return result
```
