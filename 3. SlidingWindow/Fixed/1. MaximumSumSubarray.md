#### ✅ Question  

Find the maximum sum of a subarray of size k in an array.
---

### 🔍 Algorithm
Use a fixed-size window of length k, slide it across the array, and update the sum in constant time by adding the next element and removing the first element in the window.

window size : end - start +1

possible windows : length - ws +1;

- Slide the window by incrementing `end` at every step.
- If the window size is less than `k`, continue to expand it by moving `end`.
- Once the window size equals `k`, record the sum and slide the window by moving the `start` pointer. Remove the element at `start` from the current sum.
- Continue this process until the end of the array.

---

### 🧾 Pseudo-Code

```java
FUNCTION maxSumSubarray(arr, k):
    size ← length of arr
    sum ← 0
    max ← smallest possible long value
    start ← 0
    end ← 0

    WHILE end < size:
        sum ← sum + arr[end]    // Add current element to sum

        IF (end - start + 1) < k:
            end ← end + 1        // Expand the window
        ELSE IF (end - start + 1) == k:
            max ← maximum of (max, sum)   // Update maximum sum

            sum ← sum - arr[start]   // Remove the element going out of window
            start ← start + 1        // Slide window start
            end ← end + 1            // Move window end forward

    RETURN max


MAIN:
    arr ← [2, 1, 5, 1, 3, 2]
    k ← 3
    result ← maxSumSubarray(arr, k)
    PRINT "Maximum sum of subarray of size", k, ":", result

```

---

### 💡 Time & Space Complexity

Time : O(1)

Space: O(n)
