### 🧾 Pseudo-Code

```java
FUNCTION minSubArrayLen(k, arr):
    // Initialize current subarray length
    currLen ← 0

    // Initialize current subarray sum
    currSum ← 0

    // Initialize minimum length with infinity (very large value)
    minLen ← INFINITY

    // Get the size of the array
    n ← LENGTH(arr)

    // Initialize two pointers for the sliding window
    left ← 0
    right ← 0

    // Start traversing the array with the right pointer
    WHILE right < n DO:
        
        // Add the current element to currSum
        currSum ← currSum + arr[right]

        // While current sum is greater than or equal to target k
        WHILE currSum ≥ k DO:
            
            // Calculate current window length
            currLen ← right - left

            // Update minimum length if current window is smaller
            minLen ← MIN(currLen, minLen)

            // Shrink the window from the left
            currSum ← currSum - arr[left]
            left ← left + 1

        // Move the right pointer forward to expand the window
        right ← right + 1

    // After the loop, check if we found any valid subarray
    IF minLen == INFINITY THEN:
        // No valid subarray found, return 0
        RETURN 0
    ELSE:
        // Return minimum subarray length (+1 because currLen was right - left)
        RETURN minLen + 1


```

### 💡 Time & Space Complexity

Time : O(1)

Space: O(n)
