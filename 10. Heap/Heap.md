# Heap

## Identification:

If both keywords come together : K + Largers/Smallest.

- K + Smallest : Make Max Heap
- K + Largest : Make Min Heap

Why not simply using sort?

- sorting whole array takes O(nlogn);
- whereas heap reduce to O(nlogK);
