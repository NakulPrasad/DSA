# DSA Note Helper

This extension helps you write and maintain DSA notes using a standardized template.

## Features
- **Enforce Template**: Auto-format markdown notes to a clean, standard template.
- **Diagnostics Linter**: Underline unfinished placeholders like `[Provide justification]`.
- **AI Auto-Filler**: Fill in intuition, complexity analysis, and edge cases using Ollama or Gemini.
