# Intuition

As we know stack works on the principle of last in first out, so we have to put elements in an array such that it keeps track of the most recently inserted element. Hence we can think of using a Top variable which will help in keeping track of recent elements inserted in the array.

# Algorithm

1. Declare an array of particular size.
2. Define a variable “Top” and initialize it as -1.
3. push(x): insert element is the array by increasing top by one.
4. pop(): check whether top is not equal to -1 if it is so, return top and decrease its value by one.
5. size(): return top+1.


## Pseudo-Code
---
```java

Class MyStack:
    Initialize:
        Create an array 'arr' of size 1000 to store stack elements
        Set 'top' to -1

    Method push(x):
        Increment 'top' by 1
        Set arr[top] = x

    Method pop():
        If top < 0:
            Return -1 // Stack is empty
        Else:
            Store arr[top] in temp
            Decrement top by 1
            Return temp
```
