# [Count Occurences Of Anagrams](https://www.geeksforgeeks.org/problems/count-occurences-of-anagrams5839/1)

Given a word pat and a text txt. Return the count of the occurrences of anagrams of the word in the text.

```
Example 1:

Input: txt = "forxxorfxdofr", pat = "for"
Output: 3
Explanation: for, orf and ofr appears in the txt, hence answer is 3.

Example 2:

Input: txt = "aabaabaa", pat = "aaba"
Output: 4
```

## Approach : Sliding Window

Intitution : 
- We can generate all the combination of pattern and then find them using KMP / Z-function -> Increase time complexity to O(N!)
- For sliding window, we can handle a map and update on it, but each time the window slides, we need to perform update on map. 


```java
class Solution {
    public int search(String pat, String txt) {
        int l = 0, r = 0;
        int patn = pat.length(), txtn = txt.length();
        int ans = 0;

        Map<Character, Integer> tmap = new HashMap<>();

        // Frequency map for pattern
        for (char ch : pat.toCharArray()) {
            tmap.put(ch, tmap.getOrDefault(ch, 0) + 1);
        }

        int count = tmap.size(); // Distinct character count

        while (r < txtn) {
            char ch = txt.charAt(r);

            // Decrease frequency in map
            if (tmap.containsKey(ch)) {
                tmap.put(ch, tmap.get(ch) - 1);
                if (tmap.get(ch) == 0) {
                    count--;
                }
            }

            int windowSize = r - l + 1;

            if (windowSize < patn) {
                r++;
            } else if (windowSize == patn) {
                if (count == 0) {
                    ans++; // Found a valid anagram
                }

                char lch = txt.charAt(l);
                if (tmap.containsKey(lch)) {
                    if (tmap.get(lch) == 0) {
                        count++;
                    }
                    tmap.put(lch, tmap.get(lch) + 1);
                }

                l++;
                r++;
            }
        }

        return ans;
    }
}
```
