# Max Sum Subarray of Size K

> **Difficulty:** Easy  
> **Topic / Pattern:** Sliding Window (Fixed Size)  
> **Link:** [GeeksforGeeks](https://www.geeksforgeeks.org/problems/max-sum-subarray-of-size-k5313/1)

---

## 📝 Problem Statement

Given an array of integers `arr[]` and a number `k`. Return the maximum sum of a subarray of size `k`.

Note: A subarray is a contiguous part of any given array.

### Examples
```text
Input: arr[] = [100, 200, 300, 400], k = 2
Output: 700
Explanation: arr[2] + arr[3] = 300 + 400 = 700, which is maximum.

Input: arr[] = [100, 200, 300, 400], k = 4
Output: 1000
Explanation: arr[0] + arr[1] + arr[2] + arr[3] = 1000, which is maximum.

Input: arr[] = [100, 200, 300, 400], k = 1
Output: 400
Explanation: arr[3] = 400, which is maximum.
```

---

## 💡 Intuition & Core Approach

* **The Core Idea:** Use a **Fixed-Size Sliding Window** of size `k`. As we move the window to the right, we subtract the element that goes out of the window on the left, and add the new element coming in on the right. This keeps the window sum updated in $O(1)$ time per slide, avoiding a nested loop.
* **Key Steps:**
  1. Add elements to `sum` until the window size reaches `k`.
  2. Once the window size is exactly `k`, record/update the `maxsum`.
  3. Slide the window: subtract `arr[l]`, increment `l` (left pointer) and `r` (right pointer).

---

## 💻 Implementation (Java)

```java
class Solution {
    public int maximumSumSubarray(int[] arr, int k) {
        int l = 0, r = 0;
        int sum = 0;
        int maxsum = 0;
        int n = arr.length;
        
        while (r < n) {
            sum += arr[r]; // Expand window to the right
            int windowSize = r - l + 1;
            
            if (windowSize < k) {
                r++;
            } else if (windowSize == k) {
                maxsum = Math.max(maxsum, sum); // Record max sum
                sum -= arr[l];                  // Shrink window from the left
                l++;                            // Slide window
                r++;
            }
        }
        return maxsum;
    }
}
```

---

## 📊 Complexity Analysis

| Metric | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $O(N)$ | We visit each element at most twice (once with `r` and once with `l`). |
| **Space Complexity** | $O(1)$ | No extra memory is used except for pointers and summation variables. |

---

## ⚠️ Edge Cases & Pitfalls to Avoid

* **Array size smaller than K:** If `arr.length < k`, check constraints. Usually, return `0` or throw an exception.
* **Integer Overflow:** If elements are very large, `sum` might exceed `Integer.MAX_VALUE`. In such cases, use `long` for the sum (and return `long` if the platform signature allows).
