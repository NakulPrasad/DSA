# [Permutation in String](https://leetcode.com/problems/permutation-in-string/description/)

Given two strings s1 and s2, return true if s2 contains a permutation of s1, or false otherwise.

In other words, return true if one of s1's permutations is the substring of s2.
```
Example 1:

Input: s1 = "ab", s2 = "eidbaooo"
Output: true
Explanation: s2 contains one permutation of s1 ("ba").

Example 2:

Input: s1 = "ab", s2 = "eidboaoo"
Output: false
```

## Approach : Sliding Window

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int l=0, r=0, na = s1.length(), nb=s2.length();
        Map<Character,Integer> samap = new HashMap<>();
        Map<Character,Integer> sbmap = new HashMap<>();
        for(char ch : s1.toCharArray()){
            samap.put(ch, samap.getOrDefault(ch,0)+1);
        }
        while(r<nb){
            int ws = r-l+1;
            char ch = s2.charAt(r);
            char lch = s2.charAt(l);
            sbmap.put(ch,sbmap.getOrDefault(ch,0)+1);
            if(ws<na){
                r++;
            }
            else if(ws == na){
                if (sbmap.equals(samap)) return true;
                // Shrink window from left 
                sbmap.put(lch, sbmap.get(lch) - 1);
                if (sbmap.get(lch) == 0) {
                    sbmap.remove(lch);
                }
                l++;
                r++;
            }
            else if(ws > na){
                sbmap.put(lch, sbmap.get(lch)-1);
                if(sbmap.get(lch) == 0){
                    sbmap.remove(lch);
                }
                l++;
            }            
        }
        
        return false;
    }
}
```

### Same as above but clean
```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int l = 0, r = 0, na = s1.length(), nb = s2.length();
        if (na > nb) return false;

        Map<Character, Integer> samap = new HashMap<>();
        Map<Character, Integer> sbmap = new HashMap<>();

        for (char ch : s1.toCharArray()) {
            samap.put(ch, samap.getOrDefault(ch, 0) + 1);
        }

        while (r < nb) {
            char ch = s2.charAt(r);
            sbmap.put(ch, sbmap.getOrDefault(ch, 0) + 1);

            // Window size control
            if (r - l + 1 > na) {
                char leftChar = s2.charAt(l);
                sbmap.put(leftChar, sbmap.get(leftChar) - 1);
                if (sbmap.get(leftChar) == 0) {
                    sbmap.remove(leftChar);
                }
                l++;
            }

            // Check if valid permutation
            if (r - l + 1 == na && sbmap.equals(samap)) {
                return true;
            }

            r++;
        }

        return false;
    }
}
```
