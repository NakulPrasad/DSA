# [Longest K Unique Characters substring](https://www.geeksforgeeks.org/problems/longest-k-unique-characters-substring0853/1)

Given a string s, you need to print the size of the longest possible substring with exactly k unique characters. If no possible substring exists, print -1.

```
Examples:

Input: s = "aabacbebebe", k = 3
Output: 7
Explanation: "cbebebe" is the longest substring with 3 distinct characters.

Input: s = "aaaa", k = 2
Output: -1
Explanation: There's no substring with 2 distinct characters.

Input: s = "aabaaab", k = 2
Output: 7
Explanation: "aabaaab" is the longest substring with 2 distinct characters.
```
## Approach : Bruteforce 

```java
/**
 * Difficulty : Medium
 * Intitution : 
 * Time : n2
 * Space : n
 *  
 */
class Solution {

    public int longestkSubstr(String s, int k) {
        int maxLen = -1;

        for (int i = 0; i < s.length(); i++) {
            HashMap<Character, Integer> frequencyMap = new HashMap<>();
            int distinctCount = 0;

            for (int j = i; j < s.length(); j++) {
                char currentChar = s.charAt(j);

                // Update frequencyMap
                frequencyMap.put(currentChar, frequencyMap.getOrDefault(currentChar, 0) + 1);

                // Check if the frequency of the current character is 1 (first occurrence)
                if (frequencyMap.get(currentChar) == 1) {
                    distinctCount++;
                }

                // If the number of distinct elements is greater than k, break the inner loop
                if (distinctCount > k) {
                    break;
                }

                // Update maxLen
                if (distinctCount == k) {
                    maxLen = Math.max(maxLen, j - i + 1);
                }
            }
        }

        return maxLen;
   
    }
}
```

## Approach : Sliding Window

```java
/**
 * Difficulty : Medium
 * Intitution : 
 * Time : O(N)
 * Space : O(k)
*/
class Solution {

    public int longestkSubstr(String s, int k) {
        int len = s.length();
        int left = 0;
        int right =0;
        int maxLen = -1;
        Map<Character, Integer> hm = new HashMap<>();
        while(right<len){
            //adding to hashmap
            if(hm.containsKey(s.charAt(right))){
                hm.put(s.charAt(right),hm.get(s.charAt(right))+1);
            }
            else{
                hm.put(s.charAt(right),1);
            }
           
            
            //we get possible candidate for answer.
            if(hm.size()==k){
                maxLen = Math.max(maxLen, (right - left+1));
                // System.out.println(maxLen);
                // right++;
            }
            //removing elements from left 
            else if(hm.size() > k){
                while(hm.size()>k){
                    hm.put(s.charAt(left),hm.get(s.charAt(left))-1);
                    if(hm.get(s.charAt(left))==0)
                    {
                        hm.remove(s.charAt(left));
                    }
                    left++;
                }
            }
            right ++;
        }
        return maxLen;
    }
}
```
