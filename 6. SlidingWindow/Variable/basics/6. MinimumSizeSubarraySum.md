# [Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/description/)

Given an array of positive integers nums and a positive integer target, return the minimal length of a subarray whose sum is greater than or equal to target. If there is no such subarray, return 0 instead.
```
Example 1:

Input: target = 7, nums = [2,3,1,2,4,3]
Output: 2
Explanation: The subarray [4,3] has the minimal length under the problem constraint.

Example 2:

Input: target = 4, nums = [1,4,4]
Output: 1
```

```java
class Solution {
    
    public int minSubArrayLen(int k, int[] arr) {
        int currLen = 0;
        long currSum = 0;
        int minLen = Integer.MAX_VALUE; // Initialize minLen with a large value
        int n = arr.length;
        int left = 0, right = 0;

        while (right < n) {
            currSum += arr[right];
            
            while (currSum >= k) {
                currLen = right - left; // Calculate the length of the subarray
                minLen = Math.min(currLen, minLen);
                
                // Remove elements from the left until currSum is less than k
                currSum -= arr[left];
                left++;
            }
            
            right++;
        }
        
        if (minLen == Integer.MAX_VALUE) {
            return 0;
        }
        
        return minLen + 1; // Return minLen + 1 as the length (as minLen represents indices)
    }
}
```
